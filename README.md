# Locked’n 1v1 Website

This is the startup website I am currently working on for **Locked’n**, an AI-powered fitness platform focused on making workouts more competitive, fun, and interactive.

The platform allows users to join real-time exercise battles directly through their mobile phone, tablet, or iPad browser, without needing to install an app. Users can challenge friends, compete through live camera-based workouts, track reps automatically, receive form feedback, and progress through battles against other people.

The website is being built with **Next.js / React** and includes browser-based 1v1 fitness battles, friend challenges, rep tracking, form feedback, ranks, leaderboards, and gamified audio/visual effects.

## Core Features

* Real-time AI pose detection
* Exercise form feedback
* Automatic rep tracking
* Browser-based 1v1 fitness battles
* Friend invite system
* Gamified workout experience

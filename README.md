This is the startup website I am currently working on for Locked’n, an AI-powered fitness platform focused on making workouts more competitive, fun, and interactive. In addition, the platform is designed to help people exercise with correct form and perform movements properly across various exercises using real-time AI pose detection and feedback. The site is being built with Next.js/React and will support browser based 1v1 fitness battles, allowing users to challenge friends, track reps, receive form feedback, climb ranks, compete on leaderboards, and experience working out in way which is more engaging and shareable.
